## **一、团队分工（暂定）**

| 角色        | 职责             | 技能/目标                              |
| --------- | -------------- | ---------------------------------- |
| 项目经理/产品设计 | 总体规划、需求分析、任务分配 | 项目管理、文档整理、demo设计                   |
| 数据/语料负责人  | 数据收集、清洗、标注     | Python 数据处理、文本清理                   |
| 模型负责人     | 模型选择、微调、部署     | 了解小型 LLM、微调技术、PyTorch/Transformers |
| 前端/界面负责人  | Web/桌面端界面开发    | HTML/CSS/JS、Streamlit 或 Gradio     |
| 后端/接口负责人  | 模型接口、数据库管理     | Flask/FastAPI、REST API、SQLite/JSON |
| 测试/评估负责人  | 模型实验设计、性能对比    | 实验设计、指标计算（准确率、BLEU、困惑度）            |
## **二、学习目标（可达成）**
### **基础知识目标**
1. **Python 高级基础**：文本处理、文件读写、JSON/CSV操作。
2. **机器学习基础**：线性回归、分类、模型训练流程。
3. **自然语言处理基础**：
    - 分词、向量化（TF-IDF、Word2Vec）
    - Transformers 基本概念
    - 小型语言模型微调流程
4. **Web/桌面应用开发**：
    - 简单界面框架：Streamlit/Gradio
    - 数据交互与API调用
5. **实验设计与评估**：
    - 指标：准确率、BLEU、困惑度（Perplexity）
    - 可视化对比结果
### **进阶目标**
- 掌握小模型微调（LoRA/PEFT）
- 学会结合知识库增强模型生成（RAG）
- 学会团队协作和版本控制（Git/GitHub）
## **三、学习计划（约 12-14 周，可结合学期项目）**
| 周数          | 内容              | 输出/目标                                         |
| ----------- | --------------- | --------------------------------------------- |
| **1-2 周**   | **项目启动 & 技术调研** | 完成项目需求文档、选定小语言模型（如 LLaMA 2-3B、MPT-7B-小模型）     |
| **3-4 周**   | **基础学习 & 数据准备** | 学习 NLP 基础、收集开源文本数据，完成数据清理与标注                  |
| **5-6 周**   | **模型微调实验**      | 对小模型做初步微调，完成一个小型 demo（文本生成或改写）                |
| **7-8 周**   | **接口开发**        | 搭建后端 API，将模型接口化，能够接收文本输入输出结果                  |
| **9-10 周**  | **前端界面搭建**      | 使用 Streamlit/Gradio 创建交互式平台，用户可上传文本或输入 prompt |
| **11 周**    | **实验设计与指标评估**   | 对微调前后模型输出做对比分析，统计准确率、BLEU、困惑度                 |
| **12 周**    | **整合平台 & 测试**   | 将前端、后端、模型接口整合，进行团队测试                          |
| **13-14 周** | **优化与演示准备**     | UI优化、功能完善、项目展示 PPT/演示视频制作                     |

## **四、核心里程碑**
1. **M1：数据准备完成**
    - 收集 1,000~5,000 条文本数据，清洗完成
2. **M2：模型微调完成**
    - 小模型能够生成合理输出
3. **M3：平台原型上线**
    - 用户可上传文本并获取模型结果
4. **M4：实验与对比分析完成**
    - 微调前后结果对比可视化
5. **M5：可展示最终平台**
    - 前端/后端完整整合，支持演示
## **五、技术工具选择**
- **模型与微调**：Hugging Face Transformers、PEFT/LoRA
- **数据处理**：Python + Pandas + NLTK / Jieba
- **平台开发**：Streamlit 或 Gradio
- **实验评估**：Python Matplotlib/Seaborn，可视化对比结果
- **协作工具**：GitHub、Notion/石墨文档（任务管理）、Discord/微信群、飞书
## **六、团队学习策略**
- **每周小组分享**：每人汇报本周学习/实验进展
- **交叉学习**：后期模型负责人和前端负责人互相了解接口使用
- **分阶段验收**：每周检查里程碑完成情况，确保不掉队
- **资料积累**：建立团队知识库，记录学习笔记和实验结果
##  **附录**
- 追求大模型或复杂功能，**先把小模型跑起来、能生成结果**才算成功。
- 展示效果和实验对比比模型规模更吸引人。
- 可以在后期尝试加入**知识库增强生成（RAG）**，这是创新亮点。
