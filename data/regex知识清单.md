## 一、Regex 是什么？

**Regex = Regular Expression（正则表达式）** 
是一种**用于匹配字符串模式的语法规则**，用来：

- 查找
- 匹配
- 提取
- 替换
- 验证
  几乎所有编程语言（Python、Java、JS、Go、PHP 等）都支持正则。

---

## 二、核心作用

1. 校验格式（手机号、邮箱、身份证、密码）
2. 提取内容（数字、链接、标签、关键词）
3. 替换文本（敏感词、格式化）
4. 分割字符串
5. 批量文本处理（日志、爬虫、数据清洗）

---

## 三、基础元字符（必背）

| 字符   | 作用                       |
| ---- | ------------------------ |
| `.`  | 匹配任意**单个字符**（除换行）        |
| `\d` | 数字 0-9                   |
| `\D` | 非数字                      |
| `\w` | 字母、数字、下划线 `[a-zA-Z0-9_]` |
| `\W` | 非单词字符                    |
| `\s` | 空白（空格、制表符、换行）            |
| `\S` | 非空白                      |
| `^`  | 匹配**行开头**                |
| `$`  | 匹配**行结尾**                |

---

## 四、量词（控制出现次数）

| 量词      | 含义        |
| ------- | --------- |
| `*`     | 0次或多次（贪婪） |
| `+`     | 1次或多次     |
| `?`     | 0次或1次     |
| `{n}`   | 恰好 n 次    |
| `{n,}`  | 至少 n 次    |
| `{n,m}` | n～m 次     |

### 贪婪与非贪婪

- `.*` 贪婪（尽可能多匹配）
- `.*?` 非贪婪（尽可能少匹配）

---

## 五、字符集合与范围

| 表达式      | 含义                 |
| -------- | ------------------ |
| `[abc]`  | 匹配 a 或 b 或 c       |
| `[a-z]`  | 小写字母               |
| `[A-Z]`  | 大写字母               |
| `[0-9]`  | 数字                 |
| `[^abc]` | **不是** a/b/c 的任意字符 |

---

## 六、分组与引用

| 符号                           | 作用            |
| ---------------------------- | ------------- |
| `( )`                        | 分组，捕获内容       |
| `\1` `\2`                    | 引用第1、2组匹配内容   |
| `(?: )`                      | 不捕获分组（仅分组不保存） |
| 示例：                          |               |
| `(ab)+` → 匹配 ab、abab、ababab… |               |

---

## 七、选择（或）

- `A|B` 匹配 A 或 B
  示例： 
  `com|cn|net`

---

## 八、边界与定位

| 符号   | 作用    |
| ---- | ----- |
| `^`  | 行开头   |
| `$`  | 行结尾   |
| `\b` | 单词边界  |
| `\B` | 非单词边界 |

---

## 九、常用零宽断言（高级）

| 写法              | 名称     | 作用        |
| --------------- | ------ | --------- |
| `(?=...)`       | 正向先行断言 | 后面必须是…    |
| `(?!...)`       | 负向先行断言 | 后面**不是**… |
| `(?<=...)`      | 正向后行断言 | 前面必须是…    |
| `(?<!...)`      | 负向后行断言 | 前面**不是**… |
| 用途：提取、截取、不消耗字符。 |        |           |

---

## 十、经典常用正则表达式

1. **手机号**
   
   ```regex
   ^1[3-9]\d{9}$
   ```
2. **邮箱**
   
   ```regex
   ^\w+([-+.]\w+)*@\w+([-.]\w+)*\.\w+([-.]\w+)*$
   ```
3. **身份证（18位）**
   
   ```regex
   ^\d{17}[\dXx]$
   ```
4. **URL**
   
   ```regex
   https?://\S+
   ```
5. **中文**
   
   ```regex
   [\u4e00-\u9fa5]
   ```
6. **强密码（8位以上，字母+数字）**
   
   ```regex
   ^(?=.*[A-Za-z])(?=.*\d).{8,}$
   ```

## 十一、正则匹配模式（修饰符）

| 标记  | 作用            |
| --- | ------------- |
| `i` | 忽略大小写         |
| `g` | 全局匹配          |
| `m` | 多行模式（^$ 匹配每行） |
| `s` | 让 `.` 匹配换行    |

---

## 十二、Python 示例（re 库）

```python
import re
# 匹配手机号
phone = "13812345678"
result = re.match(r'^1[3-9]\d{9}$', phone)
# 查找所有数字
text = "abc123def456"
nums = re.findall(r'\d+', text)
# 替换
new_text = re.sub(r'\d+', '*', text)
```

## 十三、优点与缺点

### PROS

- 极其强大的字符串处理工具
- 简洁、通用、跨语言
- 适合复杂规则匹配

### CONS

- 可读性差（写的人懂，读的人懵）
- 过度复杂易出错
- 不适合解析 HTML/JSON 等结构化语言

---

## 十四、记住这些坑

1. **`.` 不匹配换行**，需要加 `s` 模式
2. 贪婪匹配会吞掉内容，用 `.*?` 非贪婪
3. 特殊字符必须转义：`\. \* \+ \? \[ \] \( \) \^ \$ \|`
4. 不要用正则解析 HTML（要用专门解析器）
